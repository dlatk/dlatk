=====================
--corp_topic_tagcloud
=====================
Switch
======

--corp_topic_tagcloud

Description
===========

Produces data for making topic Wordles. You must use a topic based feature table. For a NON topic based word cloud see :doc:`fwflag_tagcloud`.

Argument and Default Value
==========================

No argument. Boolean switch, default: ``False``.

Details
=======

Aliased as ``--corp_topic_wordcloud``. Runs the exact same correlation and tagcloud-data pipeline as :doc:`fwflag_topic_tagcloud`; the only difference is where the per-topic word lists come from for :doc:`fwflag_topic_lexicon` — this switch reads them from the corpus database (``-d``/``--corpdb``) instead of the separate lexicon database (:doc:`fwflag_lexicondb`). Use this when your topic lexicon lives in the same database as your corpus.

Other Switches
==============

Required Switches:

* :doc:`fwflag_f` FEAT_TABLE (must be topic based)
* :doc:`fwflag_topic_lexicon`
* :doc:`fwflag_outcome_table`
* :doc:`fwflag_outcomes` 

Optional Switches

* :doc:`fwflag_make_topic_wordclouds`
* :doc:`fwflag_tagcloud_filter` / :doc:`fwflag_no_tagcloud_filter`
