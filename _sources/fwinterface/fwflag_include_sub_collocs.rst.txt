.. _fwflag_include_sub_collocs:
=====================
--include_sub_collocs
=====================
Switch
======

--include_sub_collocs

Description
===========

When a collocation such as "happy birthday" is found in the text, it counts 1 for "happy birthday", "happy", and "birthday".

Argument and Default Value
==========================

Modifies --use_collocs

Details
=======

Modifies :doc:`fwflag_use_collocs`

Other Switches
==============

Required Switches:

* :doc:`fwflag_use_collocs`
* :doc:`fwflag_colloc_table`

Example Commands
================

.. code-block:: bash

	dlatkInterface.py -d dla_tutorial -t msgs -c user_id --use_collocs --colloc_table my_collocs --include_sub_collocs
