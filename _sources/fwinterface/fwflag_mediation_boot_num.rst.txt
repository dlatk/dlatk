====================
--mediation_boot_num
====================
Switch
======

--mediation_boot_num N

Description
===========

To be used in Mediation analysis to specify the number of repetitions for bootstrapping method during the significance test.  This has a default number of 1000 repetitions.

Argument and Default Value
==========================

Required Switches:

Details
=======

To be used in Mediation analysis to specify the number of repetitions for bootstrapping method during the significance test.  This has a default number of 1000 repetitions. 


Other Switches
==============

Required Switches:
:doc:`fwflag_mediation` :doc:`fwflag_mediation_boot` Note: there are many other required and optional switches when running :doc:`fwflag_mediation`. 

Example Commands
================

Using the packaged ``dla_tutorial`` dataset (see :doc:`../../tutorials/tut_dla`): tests whether Facebook topic 344 mediates the relationship between being a student and age, using 10,000 bootstrap repetitions.

.. code-block:: bash

	dlatkInterface.py -d dla_tutorial -t msgs -c user_id -f 'feat$cat_met_a30_2000_cp_w$msgs$user_id$16to16' \
	--outcome_table blog_outcomes --group_freq_thresh 500 \
	--mediation --path_start is_student --outcomes age --mediators 344 \
	--mediation_boot --mediation_boot_num 10000
