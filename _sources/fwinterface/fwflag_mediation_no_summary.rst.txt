======================
--mediation_no_summary
======================
Switch
======

--mediation_no_summary

Description
===========

Mediation analysis, by default, prints a summary report of all significant results (using the Sobel p value). This switch turns that off.

Argument and Default Value
==========================

Required Switches:

Details
=======

Mediation analysis, by default, prints a summary report of all significant results (using the Sobel p value). This switch turns that off.

Example Commands
================

Using the packaged ``dla_tutorial`` dataset (see :doc:`../../tutorials/tut_dla`):

.. code-block:: bash

	dlatkInterface.py -d dla_tutorial -t msgs -c user_id -f 'feat$cat_met_a30_2000_cp_w$msgs$user_id$16to16' \
	--outcome_table blog_outcomes --group_freq_thresh 500 \
	--mediation --path_start is_student --outcomes age --mediators 344 \
	--mediation_no_summary --mediation_csv
