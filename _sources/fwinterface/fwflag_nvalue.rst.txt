.. _fwflag_nvalue:
========
--nvalue
========
Switch
======

--nvalue

Description
===========

Turn on (TRUE) or off (FALSE) reporting of N (number of groups) in --csv, --rmatrix, etc

Argument and Default Value
==========================

Argument: True (to report N) or False (to not report N)

Details
=======

The argparse type is ``bool``, so on the command line ``--nvalue False`` does **not** disable it — Python's ``bool("False")`` is truthy (any non-empty string is ``True``). In practice there's no documented way to turn this off from the command line; ``N`` is reported by default and stays on. See :doc:`fwflag_conf_int`, which has the same argparse quirk.

==============

Example Commands
================

Using the packaged ``dla_tutorial`` dataset (see :doc:`../../tutorials/tut_dla`):

	dlatkInterface.py -d dla_tutorial -t msgs -c user_id -f 'feat$1gram$msgs$user_id$16to16' \
	--outcome_table blog_outcomes --outcomes age --correlate --rmatrix --csv
