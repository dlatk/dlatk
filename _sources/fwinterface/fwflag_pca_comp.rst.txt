.. _fwflag_pca_comp:
============
--pca_comp
============
Switch
======

--pca_comp VALUE [VALUE ...]

Description
===========

Value(s) for the PCA-components feature-selection parameter, used together with :doc:`fwflag_fs_params`.

Argument and Default Value
==========================

One or more strings (``nargs='+'``, ``type=str``). Default: ``None``.

Details
=======

Verified: accepted and ran without error as part of ``--fs_params --k_best 10 --pca_comp 5``. See the caveat on :doc:`fwflag_fs_params` about its downstream effect not being independently confirmed.

Other Switches
==============

Required Switches:

* :doc:`fwflag_fs_params`

Example Commands
================

Using the packaged ``dla_tutorial`` dataset (see :doc:`../../tutorials/tut_dla`):

.. code-block:: bash

	dlatkInterface.py -d dla_tutorial -t msgs -c user_id -f 'feat$1to3gram$msgs$user_id$0_05' \
	--outcome_table blog_outcomes --outcomes age --combo_test_regression --fs_params --pca_comp 5
