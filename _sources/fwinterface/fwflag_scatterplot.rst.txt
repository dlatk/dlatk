=============
--scatterplot
=============
Switch
======

--scatterplot

Description
===========

Creates a scatter plot for each pair of given variables.

Argument and Default Value
==========================

None

Details
=======

If no feature table is given then a scatter plot is created for each pair of variables listed in :doc:`fwflag_outcomes`.

If a feature table is given then a scatter plot is created for every pair of variables (feat, outcome), where feat is specified by :doc:`fwflag_feat_names` and outcome is specified by :doc:`fwflag_outcomes`.

**Known issue:** as of this writing, the code behind this switch checks ``args.hist2d`` inside its loop, but the ``--hist2d`` flag's registration is commented out in ``dlatkInterface.py`` so ``hist2d`` is never set on ``args``. Running ``--scatterplot`` currently always fails with ``AttributeError: 'Namespace' object has no attribute 'hist2d'``.


Other Switches
==============

Required Switches:

* :doc:`fwflag_outcomes`, :doc:`fwflag_outcome_table`

Optional Switches:

* :doc:`fwflag_f`, :doc:`fwflag_feat_names`

Example Commands
================

Not usable as of this writing — see Known issue above. If it's fixed, the syntax (using the packaged ``dla_tutorial`` dataset, see :doc:`../../tutorials/tut_dla`) would be:

.. code-block:: bash

	dlatkInterface.py -d dla_tutorial -t msgs -c user_id --outcome_table blog_outcomes --outcomes age gender --scatterplot
