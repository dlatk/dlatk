=================
--skip_bin_step
=================
Switch
======

--skip_bin_step

Description
===========

Skips the binning step for :doc:`fwflag_feat_flexibin`, for when the binned ("flexibin") table has already been created and you just want faster plotting.

Argument and Default Value
==========================

No argument. Boolean switch, default: ``False``.

Details
=======

**Note:** :doc:`fwflag_feat_flexibin` itself is currently broken for an unrelated reason (references never-registered ``args.gender``/``args.genderattack`` — see the Known issue on that page), so this switch has no working consumer as of this writing even when supplied correctly.

Other Switches
==============

Required Switches:

* :doc:`fwflag_feat_flexibin`

Example Commands
================

.. code-block:: bash

	dlatkInterface.py -d dla_tutorial -t msgs -c user_id -f 'feat$1gram$msgs$user_id$16to16' \
	--feat_flexibin --num_bins 10 --group_id_range 0 100 --skip_bin_step
